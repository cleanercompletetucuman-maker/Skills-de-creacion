# claude-video-skills

145 skills de Claude Code para producción audiovisual: HyperFrames, motion design, hooks virales, guion, storytelling y optimización. Las orquesta la skill `pipeline-audiovisual` (ideas → hooks → guion → dirección → producción → optimización).

- **En este repo:** las skills se cargan solas desde `.claude/skills/`.
- **En todos tus proyectos:** ejecuta `./install.sh`.

Las fuentes y licencias originales están en [SOURCES.md](SOURCES.md).
